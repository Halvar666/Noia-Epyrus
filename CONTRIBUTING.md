# Contributing

Contributions are welcome, but the project has a few structural rules.

1. Keep **Epyrus 2.2.1 default theme behavior** as the structural baseline.
2. Do not reintroduce ClassicTB2 or another obsolete complete-theme skeleton.
3. Keep Linux and Windows platform-specific behavior separate where Epyrus differs.
4. Treat Noia Fox as the visual/artwork reference rather than the application-structure reference.
5. Avoid broad CSS replacements when a narrow overlay can preserve native Epyrus behavior.
6. Test changes on both Linux and Windows whenever they touch shared code.
7. Preserve upstream copyright, attribution and license notices.
8. Update `CHANGELOG.md` and `MODIFICATIONS.md` for release-relevant changes.
