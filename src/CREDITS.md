# Credits

Noia Epyrus is a derivative theme built from several upstream sources and projects.

## Noia Fox

**David Vincent** — original author of the Noia Fox theme for Firefox and Thunderbird.

The upstream Thunderbird Add-ons listing for Noia Fox 3.1.5 states that the theme is based on the Noia Iconpack by Carlitus and that the source code was released under Mozilla Public License Version 1.1.

Original listing:
https://addons.thunderbird.net/en-US/thunderbird/addon/noia-fox/

## Noia Iconpack

**Carlitus** — author of the Noia Iconpack on which Noia Fox was based.

This repository does not make a separate licensing claim about the standalone icon pack beyond the attribution carried by the upstream Noia Fox project; the artwork here is inherited through the Noia Fox theme distribution and its licensing notices.

## Epyrus and Mozilla/Thunderbird

The structural base is the native default theme from **Epyrus 2.2.1**, including inherited Mozilla/Thunderbird theme code and platform-specific assets. Existing file-level copyright and license notices are retained.

## Noia Epyrus
